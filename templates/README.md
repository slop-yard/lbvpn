## Pool policy

| `LB_MODE` | |
| --- | --- |
| `rr` | round-robin (default) |
| `@@FIRST_REGION@@` | pin the pool to one exit |
| `host:port` | pin the pool to an explicit upstream |

Set it in `.env` and restart `lb`. The pool balances per TCP connection, not
per request; per-region ports are exact regardless.

## Notes

- Each exit is one WireGuard config = one Proton key = one of your account's
  concurrent connections.
- A `.conf` with several `[Peer]` blocks: only the first is used.
- The label comes from an `XX#NN` token found in the file (e.g. `JP#275`),
  else from the file name.
